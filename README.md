# Pipe Tools Addon

Blender add-on for procedural pipe/tube processing and object-level workflow automation.

## Features
- Pipe creation
- Pipe fillet
- Database
- Google Sheets integration
- Pipe adapter
- Pipe end
- Pipe heating
- Tube splitting
- Split preview
- Convert tube to mesh
- Object-level properties
- Blender Geometry Nodes integration
- CI/CD GitLab
