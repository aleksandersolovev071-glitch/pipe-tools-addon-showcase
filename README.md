# Pipe Tools Addon Showcase

Public showcase for **Pipe Tools**, a private Blender add-on for procedural
pipe and tube workflows.

This repository is not an installable add-on package. It contains demo media,
documentation, and public examples. The full add-on source code is private and
available only upon request.

## Highlights

- Pipe creation and object-level pipe properties
- Automatic pipe diameter setup
- Pipe fillet tools
- Pipe adapters and pipe ends
- Pipe heating metadata
- Tube splitting and split preview
- Curve-to-mesh conversion helpers
- Blender Geometry Nodes integration
- JSON database and Google Sheets data source support
